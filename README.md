# hms-micita-salud-Vela-Aparicio

Repositorio para la actividad evaluativa de la asignatura **Herramientas de Modelado de Software** (UDES). 

Este proyecto contiene el modelado funcional del sistema **MiCita Salud**, una plataforma web y móvil para la gestión de citas médicas en una IPS de Bucaramanga.

* **Jimmy Alejandro Vela Aparicio** - *Ingeniería de Software*

## Herramienta de modelado utilizada
* **StarUML (v5.x)** - Seleccionada por su soporte nativo al estándar UML 2.5 y facilidad para exportar modelos estructurados (`.mdj`).

## Estructura del repositorio
* `/src` o raíz: Archivo fuente del modelo (`.mdj`).
* `/diagrams`: Diagrama de casos de uso exportado en alta resolución (`.png`).
* `/docs`: Documento principal de la actividad en formato PDF.

## Historial de avances
El desarrollo de esta actividad se realizó aplicando control de versiones con Git, registrando avances en los componentes de análisis de requisitos, diagramación y especificación textual.
